# medxpharm

병의원-약국 매핑 · 거래처 현황 시스템의 **입구 페이지**입니다.

<https://hellobabycoder-cyber.github.io/medxpharm/>

## 이 저장소에 든 것

`index.html` 한 장뿐입니다. 앱으로 들어가는 링크와 접속 안내만 있습니다.

## 왜 앱 자체는 여기 없나

앱은 Google Apps Script 웹앱이고, 화면에 뿌리는 값은 전부 Postgres에서
가져옵니다. GitHub Pages는 정적 파일만 서빙하므로 앱을 그대로 올리면
빈 화면만 나옵니다. 앱 소스는 비공개 저장소 `medxpharm_dev` 에 있습니다.

## 주소를 공개해도 되는 이유

앱이 스스로 로그인을 받기 때문입니다. **허용명단에 등록된 회사 메일주소와
사번이 둘 다 맞아야** 들어갈 수 있고, 서버(`Code.js`)가 토큰 없는 호출을
전부 거절합니다. 주소를 안다고 데이터를 볼 수 있는 것이 아닙니다.

> **앱의 로그인을 끄면(`AUTH_ENFORCE` 속성을 `off` 로 두면) 이 저장소도
> 비공개로 돌려야 합니다.** 그때는 주소를 아는 사람 누구나 거래처 데이터를
> 보게 됩니다.

## 주소가 바뀌면

GAS 배포는 고정 ID를 쓰므로 앱 주소는 바뀌지 않습니다. 그래도 바꿔야 한다면
`index.html` 의 `#openLink` href 한 곳만 고치면 됩니다.
